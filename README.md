# 🐾 myMeowDoku 😺

숨어 있는 고양이를 모두 찾는 웹 퍼즐 게임입니다.

## 게임 방법

n×n×n그리드의 카드가 모두 뒷면으로 덮여 있습니다. 카드 앞면은 고양이 또는 돌멩이입니다.

**고양이 배치 규칙** — 이 규칙으로 고양이 위치를 추리할 수 있습니다:

- 각 행에 고양이가 정확히 1마리
- 각 열에 고양이가 정확히 1마리
- -각 높이에 고양이가 정확히 1마리
- 같은 색 카드 묶음(연결된 영역)마다 고양이가 정확히 1마리
- 고양이끼리는 대각선을 포함해 서로 붙어 있을 수 없음
(X, Y, Z 모두 한칸 이상은 떨어져있어야합니다.)

모든 판은 논리만으로 풀 수 있도록 **해가 유일한 판만** 생성됩니다.

**조작**

- **클릭**: 🐾 마킹 (고양이가 없다는 추측 표시, 다시 클릭하면 해제)
- **드래그**: 지나가는 카드 전체에 마킹 적용/해제
- **더블클릭**: 카드 뒤집기 — 고양이면 공개되고 해당 행/열/주변 8칸이 자동 마킹됩니다. 돌멩이면 보드가 진동하고 붉은 ✕가 표시됩니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저에서 열면 바로 실행됩니다.
